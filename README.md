# Extension

This repository represents a simple web extension made in React using [WXT](github.com/wxt-dev/wxt). The xtensions is in a form of a sidepanel (note that changing the directory "sidepanel" to "popup" will turn it to popup). The extension simply allows to you to manage additional context you can put to your prompts. For example, how long do you want the answer to be and so on. The default prompts are yet to be finetunned.

I Created this to:
1) Use it for the prompts.
2) Try npm package publishing and web extension publishing.
3) Play with different React state managements.
